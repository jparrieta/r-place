# r/place

A study of how communities organised on Reddit's r/place in 2017, built with language-model agents. One instrument codes each community as a case (Gioia and Eisenhardt); another, the aggregator, builds one model across all of them. This repository holds both instruments, the handlers that run them, the scripts that rebuild the data, and the aggregator's runs, pushed after every leg.

Start with [the Manual](Manual/README.md). Terms used below: a *room* is one community's folder of material, read as a case; *raw24* is a community's complete Reddit record over 24 days; the *yard* is where rooms are coded; a *drop* is what the harness delivers to the analyst at a stage; a *shelf* is the literature a stage reads. The [glossary](Manual/glossary.md) has the rest. Reviewing the method: [for reviewers](Manual/10-for-reviewers.md). An agent inspecting the repository: [llms.txt](llms.txt) and the `FOR-AGENTS.md` beside it. To check the repository without any account: `bash verify.sh`.

## Two platforms

The aggregator's instrument (v43; every version of its documents in `aggregator/instrument/VERSIONS.tsv`) runs on Claude or on Codex, and does the same work on both. Everything the analyst reads is shared except one file per platform: `aggregator/instrument/PLATFORM-claude.md` and `aggregator/instrument/PLATFORM-codex.md` name the models, efforts and reader routes, generated by `aggregator/handler/claude/gen_platform.py` from `arm.claude.json` and `arm.codex.json` beside it. Claude Code reads `CLAUDE.md`, Codex reads `AGENTS.md`, and each points to its own platform file. To run on Claude: the harness in `aggregator/handler/claude/` (`step.sh`, `close.sh`; [HANDLER.md](aggregator/handler/HANDLER.md)), driven by the leg handler, `aggregator/handler/claude-adapter/legs.py` ([LEGS.md](aggregator/handler/claude-adapter/LEGS.md)). To run on Codex: `python3 aggregator/handler/codex/run.py` and the controller in `aggregator/handler/codex/runtime/` ([OPENAI.md](OPENAI.md), [FLEET-ARMS.md](FLEET-ARMS.md)). Both read the same input, `aggregator/input/`; each run has its own folder in `aggregator/runs/` (today `claude-v43-1/`), and the Claude build writes `CONTROL/PLATFORM`. Which files are shared, Claude's or Codex's, and what changed from each v40 copy: [OWNERSHIP.tsv](OWNERSHIP.tsv); the reasoning: the v41 entry of [the instrument's change log](aggregator/instrument/CHANGELOG-v37-to-v38.md).

## Data availability

All data are public or built from public sources. The pixel record and the username table come from archive.org; the atlas from placeAtlas/atlas-2017 on GitHub, pinned to one commit; every Reddit text from the arctic-shift archive. `data/` holds no data: each store's script downloads it or builds it where the next step looks for it, and checks it against the study's counts. What the handlers need to run is inside their folders: the census that decides which communities are rooms (`coder/census/`, which records judgements and cannot be regenerated; see [the census](Manual/census.md)), and the aggregator's inputs (`aggregator/input/`). The texts are Reddit users' words under their account names, and the pixel record can be linked back to them: read [the terms](Manual/data-and-collection.md#terms-of-use) before publishing anything drawn from them.

## Computational requirements

Reading, checking and `verify.sh`: Python 3.11 with numpy, scipy and pandas, bash, and zstd; minutes on a laptop. Rebuilding the pixel stores: numpy and Pillow, 2 GB free, about 10 minutes. Collecting the text stores: days at the archive's pace, 80 GB. Coding: Codex (OpenAI). The aggregator: Claude Code on a subscription and an OpenRouter key for its reader fleets, or Codex with the controller in `aggregator/handler/codex/runtime/` (Python 3.11). Details, where the text goes, and what is not recorded yet (costs of a whole run): [requirements and data](Manual/requirements-and-data.md).

## Instructions, in order

1. **Data.** Follow [data/README.md](data/README.md): the pixel record, the atlas, the placer accounts, the venues, raw24, the pixels per artwork, and the hourly pixels. The last three take minutes; the text stores take days.
2. **Code the rooms.** Open the yard handler ([coder/README.md](coder/README.md)): it builds each census room from raw24 and runs its brief writer, coder and case lead, smallest first.
3. **Hand the rooms to the aggregator.** The aggregator handler's steps ([HANDLER.md](aggregator/handler/HANDLER.md), "Before the run"): paths, rooms, canvas, shelves, build, acceptance, the leg handler's live check, the first commit.
4. **Run the aggregator.** A Claude Code session acts as the handler and drives the legs through `legs.py`; the principal investigator talks to the agents in `legs.py chat`, or types `step.sh` and `close.sh` for each leg ([HANDLER.md](aggregator/handler/HANDLER.md), [LEGS.md](aggregator/handler/claude-adapter/LEGS.md), [resuming and talking with a leg](Manual/9-resuming.md)).

A rebuild writes every file where the run reads it, so `git diff` shows what differs from the study's run.
