Every kind of file, and why it exists

Kind of page: reference; so is every page under files/.

  • The aggregator's files: what the analyst holds at the start of a run (the documents, the coders' package, the joined store, the forests, the tools), what it writes as its memory in out/, and the harness that runs it.
  • The handler's folder: the protocol any handler of a run follows (HANDLER.md) and the scripts it runs before and around the analyst's work, with their paths set in one file.
  • The coder's files: the coder instrument v32 (the contracts and the tools), a yard room, its run and its fleet, and the case lead's saved session.
