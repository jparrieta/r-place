# The tiers: fourth-order themes and dimensions

From `fourth/fourth.jsonl`, `dimensions.jsonl` and `scheme_v2.jsonl`, by script: each dimension, its fourth-order themes (`*`: no standing element ties to it) and their third-order members: 197 third-order themes, 28 fourth-order, 8 dimensions.

**The criterion for a fourth-order theme** (stage C2, section 2): A fourth-order theme is a named group of third-order themes. No number is set for you. The count is whatever the material carries: enough that each answers a question no member answers alone, few enough that each is a step up in abstraction and not a rename of its members.
