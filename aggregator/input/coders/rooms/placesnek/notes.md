The scope rule is clear, but “account for everything you read” sits uneasily with passage-level coding of an entire 470-item room: exhaustive coding of every non-practice sentence would make the first-order record substantially less legible. I retained at least one grounded practice code in every kept thread and added the exchanges needed for supported relations.

The openings-first requirement necessarily shapes branch-A triage by revealing the week’s arc before raw reading. The contract explicitly requires that sequence; it is reported in Selection.

## Grouping review

After the counter-reading I reviewed all theme boundaries again. I did not regroup the original themes. The two late political-expansion codes extended “keeping 'No Step On Snek' while arguing over politics and ownership,” the late Purple-response code extended “helping allies fight the Void,” and the explicit “Kill it!!” passage opened its own single-code theme rather than being forced into bounded defense.

The two themes that nearly merged were “steering snek around other people's work” and “making, testing and repairing agreements.” They stayed apart because a route accommodation changes where pixels go, whereas an agreement establishes or tests a relationship and can persist even when the pixels do not follow it.

The code I would defend hardest is “reversing the banner plan to keep No Step On Snek.” The thinnest I kept is “making a design suggestion.”

## How the reading held up

I did not work from memory of a thread instead of what `read` served. I did not return to a thread because I had forgotten it; repeated item reads occurred only for the prescribed counter-reading and relation checks. Earlier threads did not become indistinct relative to later ones: the openings table, chronological windows and forest kept the phases separable. This run was not interrupted or resumed; the initial cursor was 0.

The main ambiguity remained interpretive rather than mnemonic: the same room contained coexistence instructions, aggressive exceptions, political claims, anti-political replies, bot rejection and bot use. I preserved those as differences rather than treating later or louder speakers as the community changing its mind.
