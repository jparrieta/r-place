# Lead working notes

## Before counter-reading

Provisional reading: r/foxes turned scattered attempts to draw a fox into a late collective build by sharing templates, negotiating crowded space, mixing hand placement with scripts, recruiting allies, defending against overwriting, and then keeping the lost fox alive as Pixel in the subreddit header.

Competing account: the apparent collective build may instead have been chiefly an automated, Discord-led project, while most visible subreddit members only watched, arrived late, or narrated the result afterward. If that account is stronger, the record should contain participants attributing the actual fox to bots or off-platform organisers, saying ordinary members did not place it, or repeatedly describing themselves as missing the effort rather than building and defending it.

The first consolidation attempt reached four valid themes before the instrument refused an overlapping assignment of `c0011`; the overlap was removed and consolidation resumed. The early recruitment codes remain in “getting a fox started together.”
