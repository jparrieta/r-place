## What was hard

The hardest distinction was between hostile damage and the room's own maintenance. Posts often called changed pixels attacks, while comments sometimes identified old scripts, stale views, or defenders restoring the wrong design. I kept the claims at speaker level and did not turn every damaged pixel into either anti-ace hostility or innocent error.

The second difficult boundary was between expanding the flag and negotiating coexistence. “Expand,” “overtake,” and “territorial” are participants' words, but many uses explicitly avoid covering allies, offer space to neighboring art, or prefer a smaller defensible area. I therefore retained a territorial strand without using it as a summary of the whole case.

External images, linked scripts, private messages, Discord, other subreddits, pxls.space, and PlaceTwo show where conduct went, but not everything done there. I treated only participants' returned descriptions as evidence.

## How the reading held up

The case-lead run was checkpointed between dispatch, collection, and consolidation turns. At each resumption I read `out/ledger.md` and `out/_lead_notes.md` rather than reconstructing progress from conversational memory. Before consolidation I had read openings for orientation but no raw threads, as branch B requires. During consolidation I worked from each slice case beside that slice's pooled codes, then read the forest in full. Earlier slices did not become indistinct relative to later ones because the ledger, slice cases, and ordered code file remained the working record.

I did not work from memory of a raw thread. I went back through `read item` only after step 4, first for every counter-search hit and then for key passages used in the account; this was to verify exact wording and sequence, not because I had forgotten an earlier raw-thread reading. No whole thread had to be opened during the counter-reading because all search hits used for late codes were in threads a fleet coder had read in full.
