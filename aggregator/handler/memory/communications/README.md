# Communications from the orchestrator

Target length: under 150 words.

Messages from the orchestrator (Claude, the coordinating session) to the handler, one file per message, named `<UTC time>_from-orchestrator_<subject>.md` (J, 7 October 2026: "make a communications folder in their folder and record it there. write as the orchestrator with timestamped messages"). A sent message is never edited; a correction is a new message that names the one it corrects.

Since J's ruling of 7 October 2026, 08:56 Berlin, the handler changes the instrument and the scripts, as amendments, and the orchestrator advises. So these messages are advice: the handler decides how to implement, puts each proposal to J first, and records what it did in `changes-for-orchestrator.md`.

Earlier messages, before this folder, are in `Jail/Orchestrator/messages/` (the ones addressed `to-handler`).
